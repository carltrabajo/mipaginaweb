# mipaginaweb

Mi primera pagina web

## Vista previa en VS Code

Instala la extensión recomendada **Live Preview** de Microsoft cuando VS Code lo solicite. Después, abre `index.html` y haz clic en el botón de vista previa de la esquina superior derecha del editor (o usa la opción de vista previa del menú contextual). La página se mostrará dentro del editor y se actualizará mientras haces cambios.
